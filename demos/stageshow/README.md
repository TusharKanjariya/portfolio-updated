# Separate portfolio concept

Run `npm install`, then `npm run dev` here. Open http://127.0.0.1:4174/.
This demo is isolated: the portfolio's index.html, styles.css and script.js are unchanged.

Stageshow's ai-chat example and kit are the starting point (MIT; see LICENSE).
The document, answer and interface are illustrative, not an actual product capture.
The scene plays once, has an explicit replay, and shows a completed poster with reduced motion.

Do not deploy this whole demo dependency bundle into the portfolio without a production integration pass. A lightweight still or lazy-loaded, selectively bundled animation would be preferable.
